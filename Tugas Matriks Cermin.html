Transformasi Geometri

Halaman ini berisi analisis perpindahan titik koordinat menggunakan matriks translasi berdasarkan pergerakan objek.

1. Analisis Perhitungan Matriks

Transformasi A ke B (Vertikal - Bawah 2)
Asal: (2, 3) | Tujuan: (2, 1)
x' = x + a → 2 = 2 + a → a = 0
y' = y + b → 1 = 3 + b → b = -2
Matriks Translasi: T = [0, -2]T

Transformasi B ke C (Horizontal - Kanan 2)
Asal: (2, 1) | Tujuan: (4, 1)
x' = x + a → 4 = 2 + a → a = 2
y' = y + b → 1 = 1 + b → b = 0
Matriks Translasi: T = [2, 0]T

Transformasi D ke E (Vertikal - Bawah 4)
Asal: (2, 4) | Tujuan: (2, 0)
x' = x + a → 2 = 2 + a → a = 0
y' = y + b → 0 = 4 + b → b = -4
Matriks Translasi: T = [0, -4]T

Transformasi E ke F (Horizontal - Kanan 2)
Asal: (2, 0) | Tujuan: (4, 0)
x' = x + a → 4 = 2 + a → a = 2
y' = y + b → 0 = 0 + b → b = 0
Matriks Translasi: T = [2, 0]T

2. Ringkasan Matriks

Pergerakan Jenis Transformasi Matriks (T)
A → BVertikal (Bawah 2)[0, -2]T
B → CHorizontal (Kanan 2)[2, 0]T
D → EVertikal (Bawah 4)[0, -4]T
E → FHorizontal (Kanan 2)[2, 0]T

3. Kode Implementasi Python

import numpy as np
import matplotlib.pyplot as plt
from matplotlib import animation
from IPython.display import HTML

x_coords = np.array([2, 3, 3, 2, 2])
top_y_init = np.array([3, 3, 4, 4, 3])
bottom_y_init = np.array([-4, -4, -3, -3, -4])

fig, ax = plt.subplots(figsize=(10, 10))
ax.set_xlim(-8, 8)
ax.set_ylim(-8, 8)
ax.set_aspect('equal')
ax.set_xticks(np.arange(-8, 9, 1))
ax.set_yticks(np.arange(-8, 9, 1))
ax.grid(True, linestyle='-', alpha=0.3)
ax.axhline(0, color='black', linewidth=3)
ax.axvline(0, color='black', linewidth=1)

line_top, = ax.plot([], [], color='blue', linestyle='--', linewidth=3, label='Matriks Atas')
line_bottom, = ax.plot([], [], color='red', linestyle='--', linewidth=3, label='Matriks Bawah')

texts_top = [ax.text(0, 0, '', color='blue', fontweight='bold', ha='center', va='bottom') for _ in range(4)]
texts_bottom = [ax.text(0, 0, '', color='red', fontweight='bold', ha='center', va='top') for _ in range(4)]

ax.legend(loc='upper right')

def animate(frame):
    curr_top_y = top_y_init - frame
    curr_bottom_y = bottom_y_init + frame
    line_top.set_data(x_coords, curr_top_y)
    line_bottom.set_data(x_coords, curr_bottom_y)
    for i in range(4):
        texts_top[i].set_position((x_coords[i], curr_top_y[i]))
        texts_top[i].set_text(f'({x_coords[i]},{curr_top_y[i]})')
        texts_bottom[i].set_position((x_coords[i], curr_bottom_y[i]))
        texts_bottom[i].set_text(f'({x_coords[i]},{curr_bottom_y[i]})')
    return [line_top, line_bottom] + texts_top + texts_bottom

ani = animation.FuncAnimation(fig, animate, frames=9, interval=800, blit=True)
plt.close()
HTML(ani.to_jshtml())
