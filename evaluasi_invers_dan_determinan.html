Evaluasi Invers dan Determinan Matriks#

Halaman ini berisikan evaluasi komputasi untuk menghitung nilai invers dan determinan dari suatu matriks persegi menggunakan pustaka komputasi numerik NumPy pada Python.

Pembuktian relasi fundamental matriks dan inversnya: $$\text{Jika } A \cdot A^{-1} = I \text{, maka } \det(A) \neq 0$$
KODE PYTHON (INPUT) 
import numpy as np

# Mendefinisikan matriks persegi 3x3
A = np.array([
    [4, 2, 1],
    [3, 5, 2],
    [1, 2, 3]
])

print("Matriks A:")
print(A)

# Menghitung nilai Determinan
det_A = np.linalg.det(A)
print("\nDeterminan dari matriks A:")
print(round(det_A, 4))

# Mengecek keujudan Invers berdasarkan nilai determinan
if det_A != 0:
    inv_A = np.linalg.inv(A)
    print("\nInvers dari matriks A:")
    print(inv_A)
    
    # Validasi hasil perkalian A dikali dengan Inversnya (Harus mendekati Matriks Identitas)
    print("\nValidasi A * Inv(A) [Matriks Identitas]:")
    print(np.round(np.dot(A, inv_A), 4))
else:
    print("\nMatriks Singular: Invers tidak dapat ditemukan karena determinan bernilai 0.")
OUTPUT EKSEKUSI PROGRAM

Sifat Penting Determinan & Invers

  • Matriks Non-Singular: Matriks yang memiliki nilai determinan tidak sama dengan nol ($\det(A) \neq 0$) sehingga matriks tersebut dipastikan memiliki invers.
  • Matriks Singular: Matriks dengan determinan bernilai nol, di mana baris atau kolomnya saling bergantung linier, sehingga inversnya tidak terdefinisi.
