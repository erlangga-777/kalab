Transformasi Geometri: Analisis Titik

Halaman ini berisi analisis perpindahan titik koordinat menggunakan matriks translasi.

1. Transformasi A ke B

Asal: (2, 3) | Tujuan: (2, 1)

x' = x + a → 2 = 2 + a → a = 0
y' = y + b → 1 = 3 + b → b = -2

Matriks Translasi: T = [0, -2]T

2. Transformasi B ke C

Asal: (2, 1) | Tujuan: (4, 1)

x' = x + a → 4 = 2 + a → a = 2
y' = y + b → 1 = 1 + b → b = 0

Matriks Translasi: T = [2, 0]T

3. Transformasi D ke E

Asal: (2, 4) | Tujuan: (2, 0)

x' = x + a → 2 = 2 + a → a = 0
y' = y + b → 0 = 4 + b → b = -4

Matriks Translasi: T = [0, -4]T

4. Transformasi E ke F

Asal: (2, 0) | Tujuan: (4, 0)

x' = x + a → 4 = 2 + a → a = 2
y' = y + b → 0 = 0 + b → b = 0

Matriks Translasi: T = [2, 0]T

Ringkasan Matriks

Pergerakan Jenis Transformasi Matriks (T)
A → B Vertikal (Bawah 2) [0, -2]T
B → C Horizontal (Kanan 2) [2, 0]T
D → E Vertikal (Bawah 4) [0, -4]T
E → F Horizontal (Kanan 2) [2, 0]T
